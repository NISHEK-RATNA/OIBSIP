Car Price Prediction

Project Overview

This project uses machine learning to predict the selling price of a car based on its features.

Objectives

- Explore and clean the car dataset.
- Analyze car prices and important features.
- Prepare categorical and numerical data for machine learning.
- Train and compare regression models.
- Evaluate model performance using appropriate metrics.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project File

"Car Price Prediction.ipynb"

Conclusion

This project demonstrates how machine learning regression models can be used to estimate car prices from vehicle data.
